Stage 01 Pre-Sales & AI Calling Flow (End-to-End)
Ready
1 Data Comes From CRM / Channels
Salesforce (CRM) Meta Ads 99acres / Housing
  • Lead data comes from CRM, Meta Ads or property portals.
  • Contains details like name, phone, requirement, budget, location, etc.
Example:
Name: Amit Sharma
Phone: 98765-XXXXX
Requirement: 3 BHK in Sector 62
Budget: ₹1.5 Crore
2 Ingest Into Layer 3 Backend
Layer 3 (Tenant Backend)
  • Lead data is ingested into Layer 3 backend and saved in database.
  • System checks if the customer is new or already exists (based on phone number).
  • If existing, old history and notes are merged with new data.
Example:

System found Amit already enquired in 2024 for Tower A, so his old profile is updated with new lead data.

3 Send to Layer 2 for AI Intelligence & Talking Points
Layer 2 (AI Agents / MCP)
  • Layer 3 sends the filtered lead to Layer 2.
  • Layer 2 analyzes lead details (budget, preferences, history).
  • Using intelligence (from Layer 1 if required) and its own tools, Layer 2 prepares personalized talking points and call pitch for the bot.
Example: Talking Points
  • Pitch Tower B, 14th floor corner 3 BHK
  • Fits in ₹1.5 Cr budget
  • Highlight key features
  • Ask for site visit
4 AI Calling Bot Places the Call
AI Calling Bot Service (External)
  • Layer 3 sends lead details and Layer 2 talking points to AI Calling Bot Service.
  • Bot directly calls the customer using the provided pointers.
  • Bot speaks in natural language, shares relevant property details and invites for a site visit.
Example:

"Hello Amit ji, Vida Heights mein aapke budget ke mutabiq ek corner 3 BHK available hai. Kya aap is Saturday isko dekhne aa sakte hain?"

5 Post-Call Data & State Change
Transcript Audio Recording Sentiment Response
  • After the call, AI Calling Bot Service sends the call recording, transcript and customer response to Layer 3 via webhook API.
  • Layer 3 stores all post-call data in database.
  • Based on customer response, lead state is updated:
✓ Customer Says YES
  • Lead status = Qualified
  • Lead is sent to Stage 2 (Site Visit Desk) for further processing.
✗ Customer Says NO / Not Answered
  • Lead is scheduled for retry.
  • System will trigger follow-up call after 2 days.
